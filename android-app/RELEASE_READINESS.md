# Android 商用验收状态

**当前不能宣称商用完成。** 开发 APK 供真机验证，不能据此宣称稳定完成王者荣耀对战或无人值守递归优化。

| 发布门槛 | 当前状态 | 需要的证据 |
|---|---|---|
| 候选、冻结、校验、晋级、继承、回滚 | 已实现，代码测试验证 | 实机与独立平台验证 |
| 小米/三星等设备适配 | 未验收，未发现连接设备 | 录屏、手势、停止、故障与恢复实测 |
| 完整对战能力 | 未验收，有限动作执行器 | 完整对局、英雄/经济/装备策略、延迟与稳定性 |
| 独立授权评测平台 | 未接入，仅证明协议与导入器 | 对局编排、独立观测、正式签名服务 |
| 真实改善、晋级、下一代继承 | 安卓实机证据为零 | 完整对照、录像、晋级报告与后续父版本证明 |
| 游戏方商业授权 | 按部署方合作协议与接入材料核对 | 对应模式、环境、执行方式的许可范围与实际接入验证 |
| 发布渠道 | 未确定 | 渠道政策与审核确认 |
| 商业签名、更新、隐私与运维 | 未验收 | 正式密钥、更新回滚、数据管理、故障与用户支持验证 |

Google Play 限制无障碍 API 自主规划执行操作，当前方式不能直接作为 Play 产品发布。不能通过虚报残障辅助用途、隐藏行为或混淆审核解决。其他渠道或经许可研究部署应分别核实其条款。

腾讯公开 Gamecore 协议面向测试、机器学习和研究；合作部署的实际范围以对应商业协议为准。开源 SDK、合作运行包与游戏客户端分别核对，见 [TENCENT_INTEGRATION.md](TENCENT_INTEGRATION.md)。

官方依据：
- [Google Play 无障碍政策](https://support.google.com/googleplay/android-developer/answer/10964491?hl=en)
- [腾讯 Gamecore 许可](https://github.com/tencent-ailab/hok_env/blob/master/GAMECORE.LICENSE)
- [ML Kit 条款与隐私](https://developers.google.com/ml-kit/terms)

需要真实设备、独立评测服务和授权信息后，先验收一局可复现训练局，再做固定对照与继承。不能降低门槛、替换失败样本或用合成测试填补。
